## airbnb-berlin

#### Info
- Source: https://insideairbnb.com/get-the-data/
- Snapshot: Berlin, Berlin, Germany
- Date: 19 September, 2026
- Files: listings.csv.gz, calendar.csv.gz, reviews.csv.gz, neighbourhoods.csv

#### Problem
A hosting platform wants to understand what drives listing prices and occupancy rates so it can decide where to take action.
Key question: What factors explain listing prices and occupancy rates in Berlin, and which neighborhoods or property types are undervalued?
